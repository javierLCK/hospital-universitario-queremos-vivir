# Hospital Universitario «Queremos Vivir»

## 1. Descripción del proyecto

El proyecto consiste en desarrollar un sistema de información para el Hospital Universitario «Queremos Vivir», destinado a apoyar la gestión de pacientes, los procesos clínicos y las actividades administrativas de la institución.

El sistema se basa en el documento de contexto general y los requerimientos establecidos para los diferentes departamentos del hospital.

## 2. Objetivo general

Desarrollar un sistema de información que permita gestionar de manera organizada, eficiente y segura los procesos hospitalarios, facilitando el trabajo del personal y mejorando la disponibilidad de la información.

## 3. Áreas funcionales

El sistema contempla las siguientes áreas:

* **Admisión:** registro de ingresos y salidas, búsqueda de pacientes, consulta de habitaciones disponibles y asignación de camas.
* **Cobros:** gestión de facturas, registro de pagos, pagos parciales y control de saldos pendientes.
* **Atención sanitaria:** gestión de historias clínicas, episodios médicos, análisis, medicamentos y tratamientos.
* **Farmacia:** control de prescripciones, revisión de contraindicaciones, dispensación de medicamentos y gestión de existencias.
* **Dietética y cocina:** registro de dietas, elaboración de menús, instrucciones especiales y control de entregas.
* **Administración:** gestión general del sistema, configuración de datos e informes de ocupación, ingresos y salidas.

## 4. Seguridad de la información

El sistema deberá proteger la información personal y clínica de los pacientes.

El acceso a las funcionalidades deberá limitarse según las responsabilidades de cada usuario. El personal de administración contará con los permisos generales definidos en los requerimientos del proyecto.

No se deberán almacenar en este repositorio datos reales de pacientes, contraseñas, credenciales ni información clínica identificable.

## 5. Requerimientos del sistema

Los requerimientos se documentarán por área funcional para facilitar su análisis, implementación y verificación.

La documentación contemplará:

* Requerimientos funcionales.
* Requerimientos de seguridad y control de acceso.
* Gestión de habitaciones y camas.
* Gestión de información clínica.
* Gestión de medicamentos y dietas.
* Gestión de facturación y pagos.
* Generación de informes administrativos.

## 6. Tecnologías

Las tecnologías de desarrollo se definirán durante la planificación técnica del proyecto.

## 7. Organización del proyecto

La documentación, el código fuente y las pruebas se organizarán para facilitar el mantenimiento, el seguimiento de los requerimientos y la colaboración entre los integrantes del equipo.

## 8. Estado del proyecto

**Estado actual:** configuración inicial del repositorio y organización de los requerimientos.

Las funcionalidades se considerarán implementadas únicamente cuando se hayan desarrollado y verificado.

## 9. Documento de referencia

Los requerimientos iniciales se obtienen del documento de contexto general del Hospital Universitario «Queremos Vivir».
